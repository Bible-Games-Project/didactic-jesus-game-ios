# Didactic Jesus Game — iOS (full version)

RPG Maker MZ game, published on the App Store as the paid full version.

- Bundle ID: `com.biblegamesproject.didacticjesusgame.pro`

It is managed from bgp-admin. The same full game ships on Google Play from
[didactic-jesus-game-android](https://github.com/Bible-Games-Project/didactic-jesus-game-android),
because the two stores use different app IDs. Any change to the game content has to
be pushed to both repositories.

`bun run build` copies the game into `dist/`. There is no other build step.

The history before the move to this organization comes from `biblegamesproject/didactic-jesus-game`.
